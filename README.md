# 🎲 Number Guessing Game

A fun Python-based number guessing game with difficulty levels, hints, and attempt limits.  
This project is perfect for beginners learning Python basics like loops, conditionals, and user input.

---

## 🚀 Features
- **Difficulty Levels**
  - Easy → Range 1–50
  - Medium → Range 1–100
  - Hard → Range 1–500
- **Hint System**
  - 🔥 "You're very close!" if within 10
  - 😉 "You're getting warmer." if within 20
- **Maximum Attempts**
  - Default: 10 attempts (configurable)
- **Error Handling**
  - Handles invalid inputs gracefully
